# CS50x – Introduction to Computer Science

This repository contains my personal solutions and project code for **CS50x**, Harvard University's introductory course in computer science.

## 📚 Course Overview

CS50x covers foundational topics in computer science and programming, including:

- C programming language
- Algorithms and data structures
- Memory and file I/O
- Python and SQL
- HTML, CSS, and JavaScript
- Flask web framework
- Final Project: Original application integrating course concepts

## 🧩 Contents

Each folder in this repository represents work from a problem set or project, such as:

- **pset1–pset6** – Core problems in C  
- **pset7–pset9** – Python, SQL, and Flask tasks  
- **Final Project** – Capstone project built independently

> 📝 *Content and structure may vary slightly depending on course year.*
